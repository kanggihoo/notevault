## NoteVault v0.1.0 — Kotlin 네이티브 첫 릴리스 (2026-10-01)

GitHub 의 Obsidian 볼트를 폰에서 오프라인으로 보는 Android 앱. RN(Expo) 판을 Kotlin 네이티브로 다시 만든 첫 버전이다.

### 기능
- **설정**: fine-grained PAT(저장소 하나, Contents 읽기 전용) 붙여넣기 · 저장소(owner/repo/branch) · 연결 테스트
  - 토큰은 Android Keystore(AES-GCM)로 암호화 저장, 화면에는 끝 4자리만 표시
  - 만료 7일 전부터 경고 (GitHub 응답의 만료 헤더 기준)
  - 실패 원인을 구분해 표시: 401 / 403 / 404 / rate limit / 네트워크 + GitHub 메시지
- **구독 관리**: 원격 폴더 트리(노트 수·파일 수·용량)에서 필요한 폴더만 고르기
- **동기화** (수동 버튼): 커밋이 그대로면 요청 1번으로 끝, 바뀐 파일(blob SHA)만 받음
  - 적응형 동시 다운로드(5개 시작, 429·네트워크 오류면 절반, 최대 10개)
  - 중간에 끊겨도 받은 파일은 남고 다음 동기화가 이어받음 · 취소 가능
  - 저장소를 바꾸면 이전 저장소 파일·기록을 자동 정리
- **서랍**: 받은 파일 트리 · 파일 이름 검색 · 즐겨찾기 · 최근 문서
- **노트 보기**
  - Markdown: callout · mermaid · KaTeX 수식 · 코드 강조와 복사 버튼 · 표 · `==하이라이트==` · frontmatter 숨김
  - `[[위키링크]]`·`[글자](../상대.md)` 로 다른 노트 이동 (Obsidian 처럼 가까운 폴더 우선)
  - `![[이미지]]` 를 볼트 전체에서 찾음 — RN 판에서 `attachments/` 이미지가 "이미지 없음" 으로 나오던 문제 해결
  - `.html` 은 상대 경로 css·js 까지 그대로 · 이미지는 그림으로 · PDF 등 나머지는 다른 앱으로 열기

### 설치
1. 아래 **Assets** 의 `notevault-v0.1.0.apk` 를 폰에서 내려받는다
2. 파일을 열고 "출처를 알 수 없는 앱 설치" 를 허용한다
3. 앱 → 설정 → PAT·저장소 입력 → **저장하고 연결 테스트** → 구독 관리 → 폴더 선택 → **저장하고 동기화**

> **이전에 디버그 빌드(`com.ssafy.notevault.kotlin`)를 설치했다면 먼저 지워야 한다.** 디버그 빌드는 서명 키가 달라 이 APK 로 덮어쓸 수 없다.
> 이번 릴리스부터는 같은 키로 서명하므로, 다음 버전부터는 덮어쓰기로 업데이트된다 (토큰·받은 파일 유지).
> RN 판 앱(`com.ssafy.notevault`)과는 별개 앱이라 같이 설치된다.

### 확인한 것 / 못 한 것
- ✅ 단위·통합 테스트 118개, 에뮬레이터 E2E 4개(설정 → 구독 → 동기화 → 서랍 → 노트 렌더링 → 위키링크), 렌더러 JS 테스트 28개 — 모두 가짜 GitHub 데이터로 통과
- ✅ 이 APK 의 서명 검증 (APK Signature Scheme v2)
- ⏳ **실제 볼트·실제 PAT 로는 아직 써 보지 않았다.** 이 릴리스 APK 를 기기에서 실행한 확인도 아직이다 (같은 코드의 디버그 빌드로는 확인).

### 알려진 한계
- 동기화는 수동 버튼만 (백그라운드 주기 동기화 없음)
- 검색은 파일 이름만 (본문 검색 없음)
- 받지 않은 폴더의 노트로 가는 링크는 "찾을 수 없어요" 로 끝난다 (그 폴더를 구독해야 함)
- dataview 쿼리는 코드 블록 그대로 보인다 · `![[노트]]` 임베드는 링크로만 보인다
