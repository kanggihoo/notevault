### D. 알려진 한계·주의
- **E2E 는 앱 데이터를 지운다** — 실제 폰에서 돌리면 PAT 가 사라진다. E2E 전용 앱 ID(빌드 타입 분리)를 두면 해결된다 (미구현).
- **디버그 서명** — 다른 PC 에서 빌드한 APK 는 덮어쓸 수 없다. 여러 PC 에서 빌드할 거면 공용 서명 키(저장소에 넣지 않는 `.jks`)를 정한다.
- **Windows 개발 환경 특이점** (이미 대응됨): Robolectric SDK 35 고정, DataStore 테스트는 메모리 구현, Gradle 출력은 파일로.
- 렌더러 번들은 약 4.2MB. 노트를 열 때마다 새 WebView 를 만든다 — 느리게 느껴지면 WebView 재사용을 검토.
- `CurrentWebView`(RendererViews.kt)는 E2E 전용 연결고리다. 앱 로직에서 쓰지 않는다.

## 합의된 원칙 (재논의하지 않음)

- 원천은 GitHub 저장소 하나. Syncthing·VPS·Quartz 는 쓰지 않는다.
- 인증은 fine-grained PAT(Contents 읽기 전용) 붙여넣기. 폰에서 로그인하지 않는다. 앱 안 QR 스캐너 없음.
- 폰은 받기 전용. 폰에서 볼트를 수정하지 않는다.
- 스택: Compose·Room·OkHttp·kotlinx.serialization·Coroutines/Flow·DataStore+Keystore, Hilt 없이 `AppContainer`.
- 작업 방식: 단계마다 개념을 짧게 설명 → 테스트 먼저 → 구현 → 이해 확인.
